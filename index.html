Projeto NextTrip

Plataforma visual de colaboração entre agentes de IA para planejamento de viagens personalizadas

Documentação Detalhada V.2025-05

1. Introdução e Visão Geral

Objetivo Principal

Desenvolver um sistema de planejamento de viagens que utiliza agentes de IA para criar roteiros personalizados e colaborativos, considerando múltiplas preferências e restrições dos usuários.

O sistema permite que o usuário defina preferências como tipo de passeio, horários, restrições orçamentárias e de mobilidade, e utiliza agentes de IA para gerar um roteiro otimizado que atenda a essas necessidades.

Justificativa

A complexidade do planejamento de viagens, especialmente em grupos, demanda uma solução que possa equilibrar diferentes preferências e restrições de forma eficiente. A utilização de agentes de IA permite uma abordagem mais dinâmica e personalizada para este problema.

Diferenciais

  • Agentes especializados para diferentes aspectos do planejamento
  • Interface visual que mostra o processo de decisão em tempo real
  • Capacidade de adaptação a mudanças e preferências dinâmicas
  • Foco em acessibilidade e inclusão

2. Escopo do Projeto

2.1 Funcionalidades Principais

  • Entrada de Dados:
    • Seleção de cidade/destino
    • Definição de preferências (tipo de passeio, horários, etc.)
    • Restrições orçamentárias e de mobilidade
  • Processamento:
    • Agentes especializados para diferentes aspectos
    • Colaboração entre agentes para otimização
    • Adaptação dinâmica a mudanças
  • Saída:
    • Roteiro otimizado e personalizado
    • Visualização do processo de decisão
    • Explicações das escolhas feitas

2.2 Limitações

  • Inicialmente focado em cidades principais
  • Dados de preços e disponibilidade mockados
  • Suporte limitado a idiomas no MVP
  • Integração inicial com APIs básicas

2.3 Requisitos Técnicos

  • Backend:
    • Python 3.8+
    • FastAPI para APIs
    • PostgreSQL para dados
    • Redis para cache
  • Frontend:
    • React 18+
    • TypeScript
    • Chakra UI
    • Mapbox GL JS
  • IA/ML:
    • LangChain para agentes
    • OpenAI API
    • Custom embeddings

3. Estrutura e Arquitetura

3.1 Módulos Principais

  • Agente de Preferências:
    • Analisa e prioriza preferências do usuário
    • Identifica conflitos e restrições
    • Gera perfil de viagem
  • Agente de Atrações:
    • Busca e avalia pontos de interesse
    • Considera avaliações e popularidade
    • Filtra por acessibilidade e restrições
  • Agente de Logística:
    • Otimiza rotas e tempos
    • Gerencia horários e pausas
    • Considera transporte e deslocamento

3.2 Integrações e Dependências

  • APIs Externas:
    • Google Places API (pontos de interesse)
    • OpenStreetMap (dados geográficos)
    • Weather API (previsão do tempo)
  • Serviços Internos:
    • Serviço de autenticação
    • Cache de dados
    • Serviço de logs

3.3 Fluxo de Dados

  • Entrada do usuário → Agente de Preferências
  • Agente de Preferências → Agente de Atrações
  • Agente de Atrações → Agente de Logística
  • Agente de Logística → Interface do usuário

5. Documentação Técnica

5.1 Especificações Técnicas

  • Arquitetura de Agentes:
    • Agentes modulares com comunicação via orquestrador
    • Estado compartilhado em Redis
    • Logs estruturados para análise
  • Backend:
    • API RESTful com FastAPI
    • Autenticação JWT
    • Cache distribuído
  • Frontend:
    • SPA com React e TypeScript
    • Gerenciamento de estado com Redux
    • Visualizações com Mapbox GL

5.2 Diretrizes

  • Modularidade:
    • Agentes testáveis independentemente
    • Interfaces bem definidas
    • Baixo acoplamento
  • Transparência:
    • Decisões registradas e visíveis
    • Logs detalhados
    • Explicações claras
  • Pedagogia:
    • Interface didática/educativa
    • Visualizações intuitivas
    • Feedback claro
  • LGPD:
    • Anonimização de dados
    • Coleta mínima necessária
    • Consentimento explícito

5.3 Decisões Arquiteturais

  • Escolha de Tecnologias:
    • Python/FastAPI para backend (performance e ecossistema)
    • React/TypeScript para frontend (tipagem e componentes)
    • LangChain para agentes (maturidade e flexibilidade)
  • Padrões de Projeto:
    • Repository Pattern para dados
    • Factory Method para agentes
    • Observer para eventos

7. Protótipos e Fluxogramas

7.1 Telas Principais

  • Tela 1 - Entrada:
    • Seleção de cidade/destino
    • Formulário de preferências:
      • Tipo de passeio (cultural, gastronômico, etc.)
      • Horários disponíveis
      • Restrições orçamentárias
      • Necessidades especiais
    • Botão "Gerar roteiro colaborativo"
  • Tela 2 - Processo:
    • Visualização dos agentes trabalhando:
      • Agente de Preferências
      • Agente de Atrações
      • Agente de Logística
    • Fluxo de decisões em tempo real
    • Feedback visual das escolhas
    • Opções de ajuste manual
  • Tela 3 - Resultado:
    • Mapa interativo com pontos:
      • Rota otimizada
      • Pontos de interesse
      • Paradas programadas
    • Linha do tempo detalhada:
      • Horários de cada atividade
      • Tempos de deslocamento
      • Pausas e intervalos
    • Painel de decisões dos agentes:
      • Razões para cada escolha
      • Alternativas consideradas
      • Restrições aplicadas
